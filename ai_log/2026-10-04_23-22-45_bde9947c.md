## How the split checkout works

A git **worktree** is a second working folder attached to the same repository.

| | `/Users/vincentzhou/buzzer-83` | `/Users/vincentzhou/buzzer-83-t8` |
|---|---|---|
| Branch checked out | `feat/t4_ui_restructuring_phase_3` (the T4 chat) | `feat/t8-image-support` (this chat) |
| Files on disk | phase 3's version | T8's version |

- **Shared:** both folders use the same `.git` database. Every commit, branch and remote is visible from either, and a commit in one shows up in `git log` in the other immediately.
- **Separate:** the files on disk. Switching branches in one folder doesn't touch the other.
